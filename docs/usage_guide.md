# Руководство по использованию торгового бота "Макросы"

## Введение

Данное руководство поможет вам настроить и запустить торговый бот, основанный на стратегии "Макросы". Бот разработан для автоматической торговли на криптовалютных биржах с использованием алгоритмической стратегии, основанной на анализе конкретных временных интервалов (макросов), когда крупные игроки активно управляют ценой.

## Установка

### Требования

- Python 3.8 или выше
- Доступ к API криптовалютной биржи (поддерживаются Binance, Bybit)

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/macro_trading_bot.git
cd macro_trading_bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте конфигурационный файл:
```bash
cp config/config.json config/config.local.json
```

4. Отредактируйте `config/config.local.json`, добавив свои API-ключи и настройки.

## Конфигурация

Основные параметры конфигурации:

- `api_key` и `api_secret`: Ваши API-ключи от биржи
- `testnet`: `true` для использования тестовой сети, `false` для реальной торговли
- `symbols`: Список торговых пар для мониторинга
- `risk_per_trade`: Риск на сделку (доля от депозита)
- `check_interval`: Интервал проверки в секундах
- `macro_intervals`: Список макро-интервалов для мониторинга
- `logging_level`: Уровень логирования

## Запуск бота

### Основной режим

Для запуска бота в основном режиме выполните:

```bash
python -m src.main
```

### Режим бэктестирования

Для проверки стратегии на исторических данных:

```bash
python -m src.backtest --symbol BTCUSDT --start 2023-01-01 --end 2023-06-01
```

Параметры:
- `--symbol`: Торговая пара
- `--start`: Начальная дата (формат: YYYY-MM-DD)
- `--end`: Конечная дата (формат: YYYY-MM-DD)
- `--config`: (опционально) Путь к конфигурационному файлу

## Мониторинг и логирование

Логи бота сохраняются в директории `logs/`. Для просмотра логов в реальном времени:

```bash
tail -f logs/macro_bot.log
```

## Устранение неполадок

### Проблемы с подключением к бирже

1. Проверьте правильность API-ключей
2. Убедитесь, что у ключей есть необходимые разрешения
3. Проверьте доступность биржи

### Ошибки в работе бота

1. Проверьте логи для выявления причины ошибки
2. Убедитесь, что конфигурация корректна
3. Проверьте наличие достаточного баланса на счете
