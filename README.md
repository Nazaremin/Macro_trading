# Macro Trading Bot

Торговый бот для криптовалютных бирж, основанный на стратегии "Макросы".

## Описание

Данный бот реализует торговую стратегию, основанную на концепции "Макросов" - временных интервалов, в которые алгоритмы активно управляют ценой. Стратегия использует анализ контекста рынка, выявление зон интереса и отслеживание исполнения сценариев для генерации торговых сигналов.

## Особенности

- Анализ старших таймфреймов для определения контекста
- Выявление зон интереса (ордерблоки, дисбалансы)
- Отслеживание манипуляций и снятия ликвидности
- Мониторинг макро-интервалов для исполнения сценариев
- Генерация сигналов и управление позициями
- Бэктестирование на исторических данных

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/macro_trading_bot.git
cd macro_trading_bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте конфигурационный файл:
```bash
cp config/config.example.json config/config.json
# Отредактируйте config.json, добавив свои API-ключи и настройки
```

## Использование

### Запуск бота

```bash
python src/main.py
```

### Запуск бэктестирования

```bash
python src/backtest.py --symbol BTCUSDT --start 2023-01-01 --end 2023-12-31
```
